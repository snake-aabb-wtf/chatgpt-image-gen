### 6.3 线程模型

Tk 不是线程安全的，Playwright 的同步 API 又必须在创建它的线程里使用。因此：
主线程只碰 Tk，**工作线程独占 `Client` 与浏览器**，两者通过 `queue` 通信，
主线程用 `after(100ms)` 轮询。界面全程不卡，也不存在跨线程使用 Playwright。

### 6.4 开发中踩到的环境坑（已定位并规避）

| 现象 | 定位 | 处理 |
|------|------|------|
| GUI 测试在 pytest 里间歇失败：`Can't find a usable init.tcl` | Tk 根窗口在 **fixture / 测试函数里**创建时不稳定；同样代码在**模块导入期**创建则 100% 成功。已排除输出捕获、CWD、pytest 配置、环境变量、文件读取（3000 次读 `init.tcl` 零失败）等因素 | 测试改为在模块导入期建一个根窗口并复用；GUI 测试 8/8 稳定通过（按退出码判定） |
| 误以为"多个 Tk 根"是原因 | 单独验证：一个进程里连建 10 个根窗口全部成功 | 推翻了该假设，避免留下错误的规避代码 |
| `python -m cgpt gui` 的 Tcl 库路径 | 显式钉住 `TCL_LIBRARY`/`TK_LIBRARY`（`cgpt/gui.py::_ensure_tcl_library`），只在本机确实存在对应目录时才设置 | 让"程序名不是 python.exe"的启动方式也能稳定建窗 |

> 这一节记录的是**排查过程**而非结论堆砌 —— 其中"多根窗口"的假设是错的，
> 一并写下来是为了避免后来者再走一遍。

## 7. 开发过程中被测试抓出的真实缺陷

记录在此，因为它们说明"先离线自证再联网"确实抓到了东西：

| # | 缺陷 | 性质 | 修复 |
|---|------|------|------|
| 1 | `roundtrip_is_exact` 被当作"密钥正确性证据" | **逻辑谬误**：XOR 是对合运算，`encode(decode(x,k),k)==x` 对**任意** k 成立 | 重命名为 `codec_roundtrip_matches` 并写明它不是密钥证据；改用「明文键形状」作真实旁证 |
| 2 | 载荷令牌被误判为 Fernet | **判别条件错误**：两种形态整串 base64 解码后都是 `0x80` 开头 | 改为"能否解出 UTF-8 JSON"判别，并让 JSON 形态优先 |
| 3 | RFC 6238 常量在 `tests/` 与 `selftest.py` 各存一份，后者 SHA512 密钥少 10 字符 | **DRY 漂移**，自证凭空变红 | 常量上提到 `cgpt/auth/totp.py` 单一来源 |
| 4 | `b64decode` 默认 `validate=False`，垃圾数据也能"解"出东西 | 取证工具不该静默吞垃圾 | 全部改 `validate=True`，与 JS `atob` 语义对齐 |
| 5 | 登录表单未 hydration 时点击退化成原生 GET 提交 | **真机踩坑**：URL 变成 `/auth/login?email=…` 而流程毫无进展 | 加 React 接管检测 + 提交后校验 + 最多 3 次回退重试 |
| 6 | `_find_visible` 的 timeout 形同虚设（`locator.count()` 不等待） | **真机踩坑**：MFA 输入框被整段错过 | 改为在超时窗口内轮询全部候选选择器 |
| 7 | MFA 页面只等 8 秒 | **真机踩坑**：密码通过后 `auth.openai.com` 还要过 Cloudflare，8 秒不够 | 等待放宽到 90 秒，并在拿不到输入框且未登录时**明确报错**而非静默继续 |
| 8 | 会话详情兜底路径丢掉了会话标题 | 功能缺口 | `collect_assets` 返回 `ConversationAssets`（含 title）|

第 5~7 项只有真机才能暴露；第 1~4 项只有"拿真值离线对"才能暴露。两条验证路径都不可省。

## 8. 复现步骤

```bash
# 1) 依赖
pip install -r requirements.txt && python -m playwright install chromium

# 2) 离线自证（不需要网络、不需要账号）
python tools/build_har_vectors.py     # 从 legacy/har/ 提取真值（约 2 秒）
python -m cgpt selftest               # 期望：合计 38 项，通过 38 项，失败 0 项

# 3) 真机登录
export CGPT_EMAIL='…' CGPT_PASSWORD='…' CGPT_TOTP_SECRET='…'
python -m cgpt login

# 4) 校验会话
python -m cgpt whoami

# 5) 生图
python -m cgpt generate "生成一张地球图片" --out output/earth.png
```

> 第 5 步会消耗账号 1 次 `image_gen` 额度，并触发一次真实生成。
